# 🪟 Windows UI

A lightweight C# library that brings a modern **UWP-style look** to traditional **WinForms** applications.  
Easily enhance your desktop apps with smooth visuals and a modern design system — no WPF required.

---

## ✨ Features

- UWP-style UI for WinForms
- Custom buttons, inputs, and panels
- Built-in styles for a modern look
- Easy to integrate with a lightweight codebase
